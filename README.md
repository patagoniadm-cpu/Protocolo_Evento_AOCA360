# AOCA Impacto 360

Programa de Sostenibilidad para la Industria de Eventos — Asociación Argentina de Organizadores y Proveedores de Exposiciones, Congresos, Eventos y Burós de Convenciones (AOCA).

## Formularios en este repositorio

- **`index.html`** — Protocolo AOCA Impacto 360 (Sello de Edición de eventos)
- **`venue_aoca360.html`** — Registro Ecosistema: Venues
- **`opc_aoca360.html`** — Registro Ecosistema: OPC
- **`ope_aoca360.html`** — Registro Ecosistema: OPE
- **`OFE_AOCA360.html`** — Registro Ecosistema: OFE
- **`prov_gastro_aoca360.html`** — Registro Ecosistema: Proveedores Gastronómicos
- **`prov_tecnico_aoca360.html`** — Registro Ecosistema: Proveedores Técnicos
- **`buro_aoca360.html`** — Registro Ecosistema: Burós de Convenciones

Todos envían sus datos a un único backend de Google Apps Script, que registra cada envío en Google Sheets y organiza las evidencias en Google Drive por tipo de actor.
